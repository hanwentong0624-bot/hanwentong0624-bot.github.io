ScalePainter：基于视觉自回归模型的免训练文本引导图像修复 ScalePainter: Scale-Aligned Token Control for Training-Free Text-Guided Image Inpainting with Visual Autoregressive Models

针对像素掩码与多尺度 token 网格不对齐的问题，提出基于冻结式视觉自回归模型的免训练文本引导图像修复框架；通过离散—连续 token 控制协调目标语义注入与背景保持，并以语义泄漏校正限制跨尺度残差的空间扩散。在 EditBench、BrushBench 基准上完成对比实验与消融分析。负责创新设计、实验验证与论文撰写。

#开源项目

一些从课堂和兴趣里长出来的小项目，都在 GitHub 上开源。

VoiceGasSimulator氦气变声模拟器

用于课堂展示的声学演示程序：录音后模拟吸入氢气、氦气、SF₆ 的声音变化。基于「声源—滤波模型」，用 WORLD 声码器保留基频 F0、只迁移共振峰包络——氦气让声音更尖亮，SF₆ 则更低沉。PyQt5 桌面界面，实时显示波形与声谱图。

《运筹学》课程大作业配套代码：在 CPU / 内存容量与用户分散约束下，把 VM 请求部署到尽可能少的物理服务器。实现了 0-1 整数规划、Best Fit Decreasing 贪心、改进遗传算法，并用理论下界与可行性证书验证最优性。
