# 西安交通大学入校选拔指南

面向西安交通大学新生的个人整理型静态网站，部署于 GitHub Pages：

- 选拔通知与官方入口
- 特色班型、培养机制与志愿流程
- 往年真题、白皮书和备考材料下载（轻量包与完整清晰版）
- 大学物理、数学先修与英语四级资源
- 今日浏览量与累计浏览量（CounterAPI 匿名公共计数）

## 内容更新

常用入口集中在 `index.html`：

- 最新通知：搜索 `2026 级入校选拔补充通知入口`
- 官方通知归档：搜索 `notice-archive`
- 下载资料：`downloads/`（包含原始上传包、轻量合集与单项文件）
- 课程资源：搜索 `COURSE`
- 页脚免责声明：搜索 `DISCLAIMER`

## GitHub Pages 发布

1. 将本项目所有文件放在仓库 `main` 分支根目录。
2. 进入 **Settings → Pages**。
3. 在 **Build and deployment** 中选择 **Deploy from a branch**。
4. 选择 `main` 和 `/ (root)`，保存后等待发布。

公开地址：`https://hanwentong0624-bot.github.io/`
