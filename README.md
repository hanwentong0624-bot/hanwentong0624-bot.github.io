- 志愿关系与选拔流程
- 往年真题、备考资料与下载入口
- 大学物理、数学与英语四级资源
- 今日浏览量与累计浏览量

公开地址：<https://hanwentong0624-bot.github.io/>

## 更新方式

网站采用根目录平铺结构。更新首页时只需覆盖 `index.html`；更新资料时同步替换对应 PDF、DOCX 或 ZIP 文件。
